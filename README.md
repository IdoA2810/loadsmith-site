# loadsmith.app

The public pages for Loadsmith, served by GitHub Pages from this branch's root.
Plain HTML, one stylesheet, no build step.

- `/` – support
- `/privacy/` – privacy policy
- `/delete-account/` – how to delete an account (Google Play requires a web page for this)

`CNAME` binds the custom domain. The policy's effective date is in the page
header; move it when the page changes.
